1. Overview

LiveWord translates the preacher's speech in real time and shows subtitles at the same time on a projector and on the congregation's smartphones.

FeatureDescription
Real-time translationSubtitles appear as soon as the speaker finishes a sentence
Projector displayDedicated screen with adjustable font size and colors
Phone accessCongregants view subtitles on their phones via a QR code
Per-phone languageEach person picks their own language on their own phone
Sermon scriptUpload a PDF/Word script to improve translation accuracy
Glossary & name mapImprove name recognition; fix name translations (e.g. 요한=John)
Handout & posterPrint a congregant handout / poster with the QR and languages
LanguagesEnglish, Japanese, Chinese, Spanish, French, German, Arabic, Korean

2. Installation

1Run the installer

Double-click LiveWord_Setup.exe. If a "Windows protected your PC" warning appears, click More info → Run anyway.

2Choose the install location

Keep the default folder or choose another, then click Install.

3Finish

A LiveWord icon is created on the desktop.

4Clear the Windows security warning (first time only)

On first launch, Windows Smart App Control may block the app because it isn't code-signed. To allow it:

  1. Click the Windows Start button
  2. Search for "Smart App Control" and open it
  3. Set it to Off
  4. Double-click the LiveWord desktop icon again

💡 This is a one-time step; the app runs without warnings afterward.

⚠ On first launch you must enter API keys. Read section 3 first and have your keys ready.

3. Getting API keys (one-time)

The app uses two external services. You need a key from each.

① Anthropic Claude API key (for translation)

1Sign up

https://console.anthropic.com → Sign Up (or Log In).

2Add a payment method & credits

Left menu Billing → Add payment method → enter card details → Buy credits.

💡 $5–10 is plenty to start. A one-hour weekly service costs roughly $2–5/month. Tip: turn on Auto reload so translation never stops mid-service.

3Create the API key

Left menu API Keys → + Create Key → name it → copy the key (sk-ant-api03-...) and save it in Notepad (you can't view it again after closing).

⚠ An API key is like a password. Never share it or email it. If leaked, delete it and create a new one.

② Google Cloud speech-recognition key

1Create a project

https://console.cloud.google.com → project dropdown (top) → New Project → name it → Create, then make sure it's selected.

2Link a billing account

Menu (☰) → Billing → Link a billing account → add a card. (Light usage may fall within the free tier.)

3Enable Speech-to-Text API

Search Cloud Speech-to-Text API → click Enable.

4Create a service account

Menu (☰) → IAM & Admin → Service Accounts → + Create service account → name it → role Cloud Speech Client → Done.

5Download the JSON key

Open the new service account → Keys tab → Add key → Create new key → JSON → Create. A .json file downloads — keep it.

⚠ The JSON key is like a password. Don't email or share it. If lost, delete it and create a new one.

③ ngrok account (for phone access)

1Sign up

https://dashboard.ngrok.com → Sign Up (free)

2Copy your Authtoken

Getting Started → Your Authtoken, copy the token.

3(Optional) Get a fixed domain

Domains → New Domain — one free fixed domain lets you reuse the same QR every week.

4. First run — setup screen

1Launch

Double-click the LiveWord desktop icon. A black console window opens and the server starts (don't close it).

2Open the setup screen

An operator app window opens automatically (a standalone window with no address bar/tabs). If keys aren't set yet you'll see the setup screen; otherwise the operator dashboard. If nothing opens, type http://localhost:5000/setup in a browser.

💬 On the setup screen, the "Copy question → Open Claude" buttons let free Claude (claude.ai) walk you through getting the API keys step by step.
3Enter the Claude API key

Paste the sk-ant-... key and click Test connection.

4Upload the Google key file

Use Choose file to select the downloaded .json, then Test connection.

5ngrok settings

Enter the Authtoken and, if you have one, the fixed domain.

6Save

Click Save settings → Open operator dashboard.

✓ Settings are saved in the program folder's .env file and applied automatically next time.

6. Screens explained

Operator dashboard (/operator)

  • Open display window — opens the projector subtitle screen (can be reopened anytime)
  • Start/Stop mic — begin/stop interpreting. Changing the audio input device applies immediately.
  • 🧹 Clear screen — instantly wipes accumulated subtitles on the projector and all phones (handy between service segments)
  • Language — change source / primary target language. Takes effect from the next sentence even mid-service.
  • Upload script — a PDF/Word sermon script improves accuracy
  • Glossary — add church-specific names to improve speech recognition. Uploading adds new words to the existing list (existing kept).
  • Name/term map — fix how specific words are translated (format: 한글=English, e.g. 요한=John).
  • Display settings — font size, text/background color (live on the projector)
  • QR / Handout · Poster — the phone-access QR, plus buttons to print a congregant handout (with QR) and a custom poster

Projector (display) screen (/)

  • Double-click or F11 — toggle fullscreen
  • Subtitles stack upward; older lines scroll off the top
  • Shows the operator's primary language

Congregant phone screen (/mobile)

  • Connect by scanning the QR
  • Language picker — each person can choose their own language (English, Chinese, Japanese, Spanish, French, German, Arabic, Korean)
  • ＋ / － buttons to adjust text size
  • Keeps the screen awake automatically

Printables

  • Congregant handout (/guide) — a one-page sheet with the QR, language selection, and how-to. Korean/English toggle; print or save as PDF.
  • Poster maker (/poster) — upload your church logo and enter the church name & website; the poster is built with your branding. Logo/name are saved on this computer for next time. QR, languages, and title fill in automatically; prints on one Letter-landscape page.

7. FAQ

Q. Translation feels slow

Depending on internet speed and API load, expect a 0.5–3 second delay. A wired connection is recommended.

Q. Can each person see a different language?

Yes. After scanning the QR, each person taps the language button at the top of their phone screen. Different people can watch in different languages at once. The projector shows the operator's primary language.

Cost note: only languages that someone actually selects are translated. Unused languages cost nothing.

Q. How do I fix how a name/place is translated?

On the dashboard → Name/term map, add one per line as 한글=English (e.g. 요한=John).

Q. The screen is cluttered with old subtitles

Click 🧹 Clear screen on the dashboard to wipe the projector and all phones at once.

Q. I want a poster with our church logo

Dashboard QR area → 🖼 Poster maker → upload your logo, enter church name & website → print / save as PDF. Your logo and name are saved on this computer for next time.

Q. Names or place names are recognized incorrectly

Add them via Glossary. Format: one word per line in a .txt, .pdf, or .docx file. Uploading keeps the existing list and adds new words (duplicates removed automatically).

Q. Phones can't connect after scanning the QR

Make sure ngrok is set up. The QR area on the dashboard should show an address.

Q. I accidentally closed the black console window

Double-click the desktop icon again to restart the program.

Q. How do I change an API key?

Open http://localhost:5000/setup in a browser, enter the new key, and save.

Q. How much does translation cost?

Roughly $2–5 for a one-hour weekly service. Check real-time usage in the Anthropic console.
